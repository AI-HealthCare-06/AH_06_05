## 담당 업무

각 피처를 **화면부터 서버까지 한 사람이** 맡습니다 (10/7 합의).

### 김채연: 팀장, OCR, RAG

- 팀 운영: 회의 진행, 멘토링 사전 보고와 결과 기록, 일정 관리
- OCR: 처방전, 약봉투 사진에서 약 이름과 질병 코드 읽기 (CLOVA OCR), 약 이름 맞추기
- 안전성 점검: 병용금기, 연령금기 같은 DUR 점검
- RAG: 복약 안내와 생활습관 안내문 만들기, 근거 자료(식약처 허가정보, 생활습관 팩트표)와 검색
- ERD, API 명세서 문서 관리

### 이수인: 챗봇, 공통화면

- 챗봇: 화면, 서버(질문 분류, 가드레일, 대화 기억, 답변 생성), 챗봇 API와 표
- 공통화면: 홈, 로그인, 내 정보 같은 공통 화면 (회원 탈퇴, 로그아웃, 소셜 로그인은 뒤로 미룸)
- 개발환경 셋팅 파일 (AGENTS.md, SYSTEM_DESIGN.md, DESIGN.md, Ruff, pre-commit)

### 뒤로 미룬 것

- 챌린지: 핵심 피처에 집중하려고 뒤로 미룸. 담당은 정하지 않음 (10/7)
