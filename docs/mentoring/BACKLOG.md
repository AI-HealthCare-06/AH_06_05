## 구현 단계 (sprint 3~4, 10월 중순 예정)

### API 응답 성능 기준(P95 Latency 3초) 대응

평가 기준에 "전체 API의 P95 Latency 3초 이내"가 있으나, OCR → RAG 검색 → LLM 생성 파이프라인은 수십 초가 소요될 것으로 예상됩니다.

팀 검토안: 안내문 생성을 비동기 작업으로 분리(요청 시 즉시 `job_id` 반환 후 폴링)하여 개별 API 응답은 3초 이내로 유지

확인할 점
- Latency 측정 대상이 개별 API 응답 기준인지, 최종 결과 도출까지인지
- 실제 측정값을 어떤 방식으로 제출·증빙하는지

> 실제 구현 후 측정값을 확보한 뒤 질문하는 것이 효율적이라 이후로 미룸

### 선택 구현 범위 확정

선택 구현 3개 중 "시각/음성 콘텐츠 변환(TTS)" 1개만 진행 예정
(나머지는 확장 계획으로 문서화)

확인할 점
- 선택 구현 개수가 평가상 중요한 요소인지
- 개발 속도를 확인한 뒤 추가 여부 판단

> 개발 진척도를 본 뒤 판단하는 것이 합리적이라 이후로 미룸
