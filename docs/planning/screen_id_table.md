# 화면 번호 통합표

5팀 · 2026. 9. 23 · 작성 이형준

## 규칙

| 항목 | 규칙 | 예 |
|---|---|---|
| 형식 | `영역코드-번호` | `RG-02` |
| 영역코드 | CM 공통 / MY 내정보 설정 / OC OCR / RG RAG / CB 챗봇 / RW 실천·보상 | |
| 번호 | 사용자가 거쳐 가는 순서대로 01부터 | `OC-01` → `OC-02` |
| 예외 화면 | 부모 화면 번호 뒤에 `-E1`, `-E2` | `OC-01-E1` |
| 보조 화면 | 구분 칸의 "보조" — 화면 전체가 아니라 다른 화면 위에 잠깐 뜨는 안내 · 메뉴 | `CM-03-E2` 코치 마크 · `CB-04` 첨부 메뉴 |
| 설정 화면 | 내정보(CM-05)에서 들어가는 설정 화면(대화 보관 · 알림 등)은 `MY-S` + 번호 (S = 설정). 기존 CM-06 내 정보 수정 · CM-07 회원 탈퇴는 번호 그대로 둠 | `MY-S1` |
| Figma 프레임 이름 | `ID 화면이름` | `RG-02 결과 · 안전성` |
| 요구사항 ID | 기존 정의서의 `REQ-000` 형식으로 통일 | `REQ-040` |

요구사항 ID 번호대: 회원 001~ · 업로드 010~ · OCR 020~ · 약품매칭 030~ · 안전성 040~ · 안내문 050~ · 생활습관 060~ · 챗봇 070~ · 이력 080~ · 피드백 090~ · 음성 100~ · **실천·보상 110~ (신규)**

- `REQ-OCR-001` 형식 → `REQ-010~032` 범위로 옮김 (채연)
- `REQ-HABIT-001`, `REQ-REWARD-001` 형식 → `REQ-110~` 새로 부여 (성규)
