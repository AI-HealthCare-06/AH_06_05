## 설계 방향 *(초안)*

```
[이미지 · PDF 업로드]
      ↓ OCR (CLOVA)
[약품 정보 추출]
      ↓ RAG 검색 (식약처 공공 API 기반 지식베이스)
[근거 문서 확보]
      ↓ LLM 생성
[복약 안내 · 생활습관 가이드]
```

- **RAG**를 적용해 답변 근거를 확보하고 hallucination을 줄이는 것을 목표로 합니다
- 생성 파이프라인은 응답이 길어지므로 **비동기 처리**로 분리할 예정입니다
